EnemyEdit — 绝地潜兵 2 单位替换 Mod（v0.1）

把任务里会生成的敌人，全部换成你想要的那一种。

支持虫族、光族、机族、人族四个分页，覆盖游戏当前构建里所有可被生成系统调用的战斗单位（含变种：爆裂虫族、掠食虫族、孢裂虫族、炽灼部队、喷气旅、生化人一系）。

需要 Bingus Shared Loader v15 或更高版本

安装

完全退出游戏。

用 HD2 Mod Manager / Arsenal 导入本 zip。

Deploy。

启动游戏。

使用

开每一次任务前，不建议在任务内部修改或改回默认，我只测试过尝试改回默认仍然生成选择单位，和部分生成在地上的问号

按 F9 打开 / 关闭面板，这个做的有点烂，外置窗口，任务栏隐藏的，你想用的时候就按下，没出来就再按下就行了，有时候你没关闭忘记了又不知道跑哪去了就这样得按两下

面板顶部四个分页：虫族 / 光族 / 机族 / 人族。点分页切换。

滚轮滚动列表，点击一行选中。（实际上鼠标光标和对应选中的位置有点偏差，懒得修了，能用就行，而且你肉眼也可能看到底色显示划到了哪个）

点 Apply，底部会显示 [族名] patched N/M -> 单位名，成功应用。

想换别的单位，重新选再 Apply。

想恢复原版，点 Default。

点 Close 或再按 F9 关闭窗口。

关于这个mod，我一开始想做的范围蛮大，第一个页面放当前版本的功能，然后第二个页面放多倍怪物组合可定义权重分权重组合生成的功能，这个git好像有但是没有用过不知道表现，之前打算搬，现在已经没有打算搬这方面做集成的想法了，因为太难搞了，第三个页面做某一单位的行为模式，部位血量的相关增强插件，可选开关，支持社区分享导入和导出，这个更未来，不谈了。

根据我做这个mod的推测:
生成应该是：巡逻队，刷潮 / 增援，原住民（或者说守卫点）分为任务点守卫、资源点守卫、巢落守卫，巢落内部主动生成（从虫洞、机器人构筑者里刷出来的，敌人连锁召唤（例如指挥官叫援军、虫族巢洞持续刷怪）

生成又有个判断：标签 实体 还有个taskuser感觉像一种族内某种类型单位分类，什么战士法师之类的，组件预算上限判断，场上组件总上限，跟难度和什么点：刷潮，巡逻队，守卫处啥的尝试生成判断
不能就被拒绝就没敌人。（我其实有想法做一个不能就用原来的怪生成即可的版本，但是还是没做。）
就好比对于此mod应用后，原住民会被尝试应用，你换个强袭虫，资源点，小巢落就没初始敌人了，难度低了，好比难度1，就不会有敌人，或者说基本看不见敌人巡逻队了

不生效或者会出现反直觉结果的情况（我连续改动测的几把任务表现经验）:
调取人族想替代敌人单位生成是不行的，但相关人族单位生成后确实为我选的单位（这里应该特指的是seaf单位，你别说，我还没试过撤离任务那个门里出来的人会怎么样）

在有特殊 buff 的任务里，替换会"顺着 buff 走"。比如任务带了炽灼部队 buff，你把敌人替换成"巨型者"，实际刷出来的是"巨型炙焰者"（巨型者的炽灼版本），不是普通的巨型者。这是引擎自身的替换逻辑，

在没有对应生成环境的地图里应用某些替换，可能不会生成任何单位，还可能让游戏卡顿甚至闪退。两个已确认的例子：在没有城市 / SEAF 生成条件的歼灭任务里应用人族替换，会导致单位生成平庸奇怪；替换"霸王虫"（Hivelord）这种超高组件成本的单位时，会直接卡死闪退。

小资源点守卫：原版这些点只会放最便宜的小怪（食腐虫之类），替换成强袭虫这种高成本单位时，因为单体组件消耗超过引擎当次允许的总预算，引擎会直接拒绝这一批生成，结果是一个都不刷。大巢落因为原生就放中量级单位，预算够，所以替换能成功。目前没有好的办法让引擎在小资源点上刷高成本单位

问题情况排错

mod冲突：未知，本mod一向单一mod状态测试，也并未有与多倍怪mod同时使用过

按 F9 没反应：确认 Bingus Shared Loader 已在运行（BingusSharedLoader.log 里有 loader-v15 或更新，以及 API 1），并确认本 mod 在 loader 的 Discovery 列表里是 loaded 而不是 load failed。

面板能开但 Apply 后任务里没变化：换个低组件成本的单位（Hunter、Warrior MK2、食腐虫 MK2）再试一次。

任务中闪退：强退游戏重开，进游戏前先在飞船里换一个更便宜的单位，或者点 Default 恢复原版。

日志位置：%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\，其中 enemyedit_log.txt 记录每次 Apply / Default 的结果。

卸载

退游戏，管理器停用 / 移除本 mod，重新 Deploy，重启游戏即可。所有替换只存在于进程内存里，禁用 + 重启后就恢复原状。
